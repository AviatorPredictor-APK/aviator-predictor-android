# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and public releases will follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html) where compatible with Android version-code requirements.

## [Unreleased]

### Added

- Pre-release repository documentation scaffold.
- Installation, APK verification, method, limitations, privacy, security, release, and responsible-use documentation.
- Community health files, legal notices, and issue templates.
- Deny-by-default rules for APKs, signing keys, credentials, and generated build output.

### Security

- Source migration and APK publication remain blocked until the pre-release checklist is complete.

## Release-history policy

Historical local builds must not be presented as earlier GitHub releases unless their source commits, binaries, dates, signatures, and changelog entries can be verified. The first release published with source code must explicitly identify itself as the first verifiable GitHub release.
